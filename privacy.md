# Privacy Policy - Theo doi du an

Last updated: 2026-11-21

Theo doi du an is a desktop application that runs only on the user's own Windows computer. It has no server and does not collect, sell or share any personal data.

## Google user data

When the user chooses "Sign in with Google", the app asks for access to Google Calendar. This access is used only to create one calendar named "Du an ERP - WMS" in the user's own account and to add, update and remove the project session events in that calendar. The app does not read, change or delete any other calendar or event, and does not access any other Google data.

The sign-in token is stored only on the user's computer, encrypted with Windows (DPAPI). Calendar data is sent only between the user's computer and Google. Nothing is sent to the developer or to any third party.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Removing access

The user can sign out in the app (menu Google / iPhone) or remove access at any time at https://myaccount.google.com/permissions. Deleting the calendar "Du an ERP - WMS" in Google Calendar removes all events the app created.
