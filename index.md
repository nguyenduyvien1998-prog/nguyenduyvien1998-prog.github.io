# Theo doi du an

Theo doi du an (Project Tracker) is a Windows desktop application used by an ERP / WMS implementation consultant to track customer projects: roadmap sessions, homework and meeting notes.

Ung dung Theo doi du an chay tren may tinh Windows cua nguoi dung, dung de theo doi lo trinh, bai tap va bien ban cac du an trien khai ERP / WMS.

## Google Calendar

With the user's permission, the app creates one calendar named "Du an ERP - WMS" in the user's own Google Calendar and keeps the planned project sessions in it up to date, so they can be seen on a phone.
